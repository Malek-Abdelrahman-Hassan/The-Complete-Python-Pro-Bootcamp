# Reviews

Milestone reviews consolidate a whole block of the course into one note. Each review brings together the key concepts, a combined cheat sheet, and mixed recall questions that span several days. They are written from the [review template](../templates/review.md) once the last day of the block is done.

| Milestone | Covers | Review |
| --- | --- | :---: |
| Beginner | Days 1-14 | ⬜ |
| Intermediate | Days 15-31 | ⬜ |
| Intermediate+ | Days 32-58 | ⬜ |
| Advanced | Days 59-81 | ⬜ |
| Professional Portfolio | Days 82-100 | ⬜ |

When a review is written, save it as `reviews/<milestone>.md` (for example `reviews/beginner.md`), link it in the table and change ⬜ to ✅.
